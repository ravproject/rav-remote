# Cara Mendapatkan Kredensial Telegram

Untuk menjalankan tes end-to-end, Anda perlu memberikan kredensial Telegram Anda. Berikut cara mendapatkannya:

## 1. API ID dan API Hash

1.  Buka [my.telegram.org](https://my.telegram.org) dan masuk dengan akun Telegram Anda.
2.  Klik **API development tools**.
3.  Isi kolom **App title** dan **Short name**. Anda bisa memasukkan nama apa saja yang Anda inginkan.
4.  Klik **Create application**.
5.  Sekarang Anda akan melihat **api_id** dan **api_hash** Anda.

## 2. Token Bot

1.  Buka aplikasi Telegram dan cari bot **BotFather**.
2.  Mulai obrolan dengan BotFather dan kirim perintah `/newbot`.
3.  Ikuti instruksi untuk membuat bot baru. Anda akan diminta untuk memberikan nama dan nama pengguna untuk bot Anda.
4.  Setelah Anda membuat bot, BotFather akan memberi Anda **token bot**.

## 3. ID Pengguna

1.  Buka aplikasi Telegram dan cari bot **@userinfobot**.
2.  Mulai obrolan dengan bot tersebut.
3.  Bot akan mengirimi Anda pesan dengan **ID pengguna** Anda.
